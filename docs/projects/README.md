# Projects

`docs/projects/` is for *operator docs* and *design notes* that help run, demo, or understand the app.

## What belongs here
- Demo/runbooks, deployment/triage guides
- UI rationale, screenshots, migration notes
- Architecture notes that are not a phased roadmap

## What does NOT belong here
Roadmap SSOT or phase plans.

**Do not add:**
- `PLAN.md`
- `phase-status.json`
- Roadmap PR lists / phase trackers

Canonical roadmap system lives in: `docs/roadmaps/`
