# Acceptance

- Right rail has a Run | Evidence toggle.
- Run mode shows: Minutes, Checklist, Delta/Impact/Tasks, Run history, Export/New run actions.
- Evidence mode shows Upload AOI at the top and preserves all evidence/STAC panels.
- Upload AOI and Export/New run are reachable without scrolling (sticky bar).
- Switching modes does not wipe user-entered state (e.g., STAC inputs, draft task input).
