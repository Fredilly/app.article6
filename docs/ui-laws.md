# UI Laws (SSOT)

Law 1 — One primary list per page.
Do not stack another list above the main list surface.

Law 2 — Preview → Drawer.
Use a compact summary row and open a drawer for the full list.

Law 3 — Drawer owns scroll.
The page stays stable; the drawer handles scrolling.

Law 4 — Actions are idempotent.
Repeated actions do not create duplicates.
